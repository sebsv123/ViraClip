# Archived Documentation

Historical documents that are no longer maintained but kept for reference.

These files describe work that has been completed, plans that have been executed, or older snapshots of the project that are no longer accurate. They are preserved so that contributors can understand how the project evolved.

For up-to-date documentation, see:

- [`README.md`](../../README.md) — project overview
- [`docs/`](../) — current documentation
- [`CHANGELOG.md`](../../CHANGELOG.md) — release notes

## Contents

- `root-docs/` — older one-off planning, status, and feature notes that previously lived at the repository root.
- `REFACTOR_SERVICES_PLAN.md` *(in `root-docs/`)* — the original plan for splitting the legacy `services/` directory into domains. Executed in April 2026.
- `TEST_REPORT.md` *(in `root-docs/`)* — historical test-suite snapshot prior to the backend refactor. The current test status is described in [`README.md`](../../README.md#-testing).
- `UPDATED_CHANGES.md` *(in `root-docs/`)* — pre-CHANGELOG running notes; superseded by [`CHANGELOG.md`](../../CHANGELOG.md).

If you find yourself needing information from an archived doc to do current work, please consider promoting the relevant content into the live docs and opening a PR.
